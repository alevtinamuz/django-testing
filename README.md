# Django Testing

Проект курса Яндекс.Практикум по тестированию Django-приложений: набор тестов на `pytest` и `unittest` для двух ранее написанных проектов - **YaNews** и **YaNote**.

## Описание проекта

Репозиторий объединяет два независимых Django-приложения и полный набор тестов для них, написанных в ходе изучения модуля тестирования.

### YaNews

Новостной сайт с возможностью комментирования:

- список новостей на главной странице (ограничен количеством, заданным в настройках);
- детальная страница новости с комментариями, отсортированными по времени публикации;
- добавление комментария - доступно только авторизованным пользователям;
- редактирование и удаление комментария - доступно только автору комментария.

Тесты для YaNews написаны на **pytest** (`ya_news/news/pytest_tests/`) и проверяют:
- `test_content.py` - корректность отображаемого контента (порядок новостей, видимость формы комментария, порядок комментариев);
- `test_logic.py` - бизнес-логику (создание, редактирование, удаление комментариев, фильтрацию запрещённых слов);
- `test_routes.py` - доступность страниц для разных типов пользователей (анонимный, автор, не автор).

### YaNote

Сервис заметок с приватностью по пользователю:

- создание, редактирование, удаление и просмотр заметок;
- автоматическая генерация `slug` из заголовка заметки, если он не указан явно;
- каждый пользователь видит и может редактировать только свои заметки.

Тесты для YaNote написаны в стиле **unittest** поверх `pytest-django` (`ya_note/notes/tests/`) и проверяют:
- `test_content.py` - содержимое страниц и форм;
- `test_logic.py` - создание, редактирование и удаление заметок, уникальность и генерацию `slug`;
- `test_routes.py` - маршрутизацию и права доступа для разных пользователей.

## Стек технологий

- Python 3.12.7
- Django 5.1.1
- pytest, pytest-django, pytest-lazy-fixture, pytest-subtests
- pytils - транслитерация для генерации `slug` в YaNote
- flake8, flake8-docstrings, pep8-naming - проверка стиля кода

## Как запустить

Клонировать репозиторий и перейти в него в командной строке:

```bash
git clone https://github.com/alevtinamuz/django-testing.git
cd django-testing
```

Создать и активировать виртуальное окружение:

```bash
python -m venv venv
source venv/Scripts/activate    # Windows (Git Bash)
source venv/bin/activate        # Linux / macOS
```

Установить зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск проверок

Полная проверка (стиль кода, структура репозитория, тесты обоих проектов) запускается одной командой из корня репозитория:

```bash
bash run_tests.sh
```

Скрипт последовательно выполняет:
1. `flake8` - проверку кода на соответствие PEP8;
2. `structure_test.py` - проверку структуры репозитория на соответствие ожидаемой;
3. `pytest` в `ya_news/` - тесты новостного сервиса;
4. `pytest` в `ya_note/` - тесты сервиса заметок.

Если нужно запустить тесты только одного проекта:

```bash
cd ya_news && pytest
```

```bash
cd ya_note && pytest
```
